# 第一部分：引用与常量

本目录通过四个 C++23 Notebook 介绍引用、参数传递、`const` 与生命周期。这些概念是后续理解对象所有权、RAII、Native API 参数设计和跨语言边界的基础。

## 实验目录

| 顺序 | 实验 | 大致内容 |
| --- | --- | --- |
| 1 | [引用和指针](01_reference.ipynb) | 引用的声明与初始化、引用和指针的区别、不可重新绑定等基本规则。 |
| 2 | [函数参数与引用传递](02_function_parameter.ipynb) | 值传递、引用传递的行为差异，以及函数参数为什么常使用引用。 |
| 3 | [常量](03_const.ipynb) | `const` 对象、`const T&`、常量与指针的组合，以及只读 API 的表达方式。 |
| 4 | [引用与生命周期](04_reference_lifetime.ipynb) | 引用有效期、悬空引用风险，以及按值、可变引用和常量引用的参数选择。 |

## 学习顺序

按编号依次打开 Notebook，并使用 C++23 kernel 从上到下执行单元格。Notebook kernel 会保留已执行的声明；修改函数定义后如果遇到 `redefinition`，请重启 kernel 再从头执行。

完成本部分后，应能从“是否拥有对象、是否允许修改、被引用对象能存活多久”三个角度理解 C++ 引用和参数类型。
